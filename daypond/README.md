# Daypond pages

Four-language marketing, support and privacy pages for https://saberzou.ai/daypond/.

English routes are /daypond/, /daypond/support/ and /daypond/privacy/. Localized equivalents use /zh-hans/, /ja/ and /es/.

Edit content.json, then run `python3 scripts/build-daypond.py` and `python3 scripts/check-daypond.py` from the repository root. The pages use local styles/images and no application JavaScript. The approved koi-only icon is retained. No App Store download link is shown before availability is verified.
